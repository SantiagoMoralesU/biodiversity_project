# Biodiversity in National Parks

An analysis of National Park Service data on the species recorded in four US national parks
(Bryce, Great Smoky Mountains, Yellowstone and Yosemite), asking whether some types of species
are more likely to be endangered than others. Built as a Codecademy portfolio project.

## Files
- `biodiversity.ipynb`: the full analysis, charts and conclusions
- `species_info.csv` and `observations.csv`: the data

## Tools
Python, pandas, matplotlib, seaborn, scipy and Jupyter Notebook
